# React Bits

The continuous gallery adapts wrapping, frame-delta and drag-momentum ideas from React Bits ScrollVelocity, with a curved composition inspired by CircularGallery. This is a plain-JavaScript adaptation for this website, not an installed React component.

Sources inspected 13 November 2026:
- https://github.com/DavidHDev/react-bits/blob/main/src/content/TextAnimations/ScrollVelocity/ScrollVelocity.jsx
- https://github.com/DavidHDev/react-bits/blob/main/src/content/Components/CircularGallery/CircularGallery.jsx
